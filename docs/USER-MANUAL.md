# WonderWoW - User Manual

## 1. Installation

1. Copy `WonderWow_v11.apk` (in the `apk/` folder of this repository) to the Android device.
2. On the device, open Settings and allow installation of applications from unknown sources for the app you will use to open the file (for example the file manager or browser).
3. Open the APK file on the device and confirm the installation.
4. Start WonderWoW from the app drawer.

Requirements: Android 5.1 or newer. An internet connection is required the first time most games are opened (see section 3).

## 2. Using the Dashboard

- The dashboard shows six game cards.
- Tap a card to open that game. A short loading screen is shown while the game starts.
- Inside a game, press the device back button (or the in-game back control) to return to the dashboard.
- Pressing the back button on the dashboard itself closes the application.

## 3. Game Guide

### 3.1 Realm Guardians
A tower defence game. Choose a map, then build towers on the battlefield and stop the monster waves before they reach the exit.

- Four tower types are available: Fire Blaster (splash damage), Ice Cannon (slows enemies), Leaf Shooter (poison) and Magic Laser (long-range sniper).
- Gold is earned by defeating enemies; it is spent on towers and lifelines.
- Lifelines: Meteor (area damage), Freeze (stops enemies briefly) and Heal (restores lives).
- Each map has a set number of waves; the fourth map ends with the strongest enemies.

Note: this game loads part of its content from the internet; connect the device before playing.

### 3.2 Jungle Animals
Tap any animal in the scene to hear its sound, see its name appear and hear the name spoken aloud. Fifteen animals are included.

Note: animal pictures and sounds are streamed from the internet.

### 3.3 Coloring World
Pick a colour from the crayon palette and colour the picture by touching the screen. Sound effects play as you draw.

Note: some resources load from the internet.

### 3.4 Pip's Adventure
Help Pip reach the house at the end of each level. A short instruction is shown for every obstacle, for example "Jump on the Rock!" or "A bonfire blocks the path! Use Water." Perform the correct action to solve the obstacle and continue. There are 20 levels with four environment themes; after the last level the adventure continues from the beginning.

Note: this game loads part of its content from the internet.

### 3.5 Scratch & Match
Twelve tiles hide six pairs of cartoon pictures.

- Scratch a tile with your finger: drag across the surface to rub it off. About one third of the tile must be scratched before the picture is revealed.
- Revealed tiles stay visible, so you can use the board to remember where each picture is.
- Find each matching pair; every matched pair adds 20 coins to the counter at the top.
- When all six pairs are found, the board celebrates and reshuffles for a new round.

Works completely offline.

### 3.6 Puzzle Fun
A 3x3 sliding puzzle.

- A short "How to Play" overlay appears the first time you open the game.
- Tap a tile that is next to the empty space; the tile slides into the empty spot.
- Rearrange all tiles into the correct order to solve the puzzle. The game plays a victory sound and shows how many moves you used.

Works completely offline.

## 4. Troubleshooting

| Problem | What to do |
| --- | --- |
| A game shows blank or unstyled content | Connect the device to the internet and reopen the game; four games load resources from the internet on first use. |
| No animal sounds in Jungle Animals | Check the media volume and make sure the device is online. |
| The app does not install | Allow installation from unknown sources and check that the device runs Android 5.1 or newer. |
| The screen orientation does not change | Most games intentionally lock landscape orientation; rotate the device physically. |
| Game progress or coins were lost | Coins and progress are not saved between sessions; this is expected. |
